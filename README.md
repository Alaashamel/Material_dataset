# Material Dataset

![License](https://img.shields.io/badge/license-MIT-blue.svg) ![Language](https://img.shields.io/badge/language-Python-informational.svg) ![Last Commit](https://img.shields.io/github/last-commit/Alaashamel/Material_dataset)


Deep learning project for material classification using PyTorch, scikit-learn, and Grad-CAM for model explainability, with a Streamlit GUI for viewing predictions and results.
## ✨ Features

- Built primarily with **Python**
- Clean, organized project structure
- Actively maintained on GitHub

## 🛠️ Tech Stack

- **Language:** Python
- **Package manifest:** `requirements.txt`

## 🚀 Getting Started

```bash
git clone https://github.com/Alaashamel/Material_dataset.git
cd Material_dataset
pip install -r requirements.txt
```
